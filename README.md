Network Security Assessment

About the Project

This project documents a hands-on network security assessment conducted in a controlled lab environment. It focuses on network reconnaissance, port scanning, service enumeration, and identifying potential security risks.

Objectives

* Discover hosts and open ports.
* Identify running services and versions.
* Practice network reconnaissance using Nmap.
* Document findings and security recommendations.

Tools Used

* Kali Linux
* Nmap
* Linux command-line tools

Methodology

1. Identify target hosts in the authorized lab.
2. Scan for open ports and running services.
3. Enumerate discovered services.
4. Analyze potential security risks.
5. Document findings and recommendations.

Scope

All testing is performed in an authorized lab environment. No unauthorized systems are scanned.
